# Package index

## Functions

Functions for preparing the data, fitting regressions, selecting best
models, and plotting results

- [`PCOload()`](https://aagillet.github.io/MorphoRegions/reference/PCOload.md)
  [`plot(`*`<regions_pco_load>`*`)`](https://aagillet.github.io/MorphoRegions/reference/PCOload.md)
  : Calculate PCO loadings
- [`PCOselect()`](https://aagillet.github.io/MorphoRegions/reference/PCOselect.md)
  [`plot(`*`<regions_pco_select>`*`)`](https://aagillet.github.io/MorphoRegions/reference/PCOselect.md)
  [`summary(`*`<regions_pco_select>`*`)`](https://aagillet.github.io/MorphoRegions/reference/PCOselect.md)
  : Select PCO scores
- [`calcBPvar()`](https://aagillet.github.io/MorphoRegions/reference/calcBPvar.md)
  : Calculate variability of breakpoints
- [`calcmodel()`](https://aagillet.github.io/MorphoRegions/reference/calcmodel.md)
  : Calculate results of a single segmented regression model
- [`calcregions()`](https://aagillet.github.io/MorphoRegions/reference/calcregions.md)
  [`addregions()`](https://aagillet.github.io/MorphoRegions/reference/calcregions.md)
  [`summary(`*`<regions_results>`*`)`](https://aagillet.github.io/MorphoRegions/reference/calcregions.md)
  [`ncombos()`](https://aagillet.github.io/MorphoRegions/reference/calcregions.md)
  : Fit segmented regression models for all combinations of breakpoints
- [`modelperf()`](https://aagillet.github.io/MorphoRegions/reference/modelperf.md)
  : Assess model performance
- [`modelselect()`](https://aagillet.github.io/MorphoRegions/reference/modelselect.md)
  : Select the best models
- [`modelsupport()`](https://aagillet.github.io/MorphoRegions/reference/modelsupport.md)
  : Evaluate model support
- [`plot(`*`<regions_pco>`*`)`](https://aagillet.github.io/MorphoRegions/reference/plot.regions_pco.md)
  : Plot PCO axes
- [`plotsegreg()`](https://aagillet.github.io/MorphoRegions/reference/plotsegreg.md)
  : Plot a segmented regression model
- [`plotvertmap()`](https://aagillet.github.io/MorphoRegions/reference/plotvertmap.md)
  : Plot a vertebra map
- [`simregions()`](https://aagillet.github.io/MorphoRegions/reference/simregions.md)
  [`plot(`*`<regions_sim>`*`)`](https://aagillet.github.io/MorphoRegions/reference/simregions.md)
  : Simulate regions data
- [`process_measurements()`](https://aagillet.github.io/MorphoRegions/reference/process_measurements.md)
  : Process vertebra measurements
- [`subsample()`](https://aagillet.github.io/MorphoRegions/reference/subsample.md)
  : Subsample a dataset
- [`svdPCO()`](https://aagillet.github.io/MorphoRegions/reference/svdPCO.md)
  : Calculate PCO (principal co-ordinates analysis) based on SVD

## Datasets

- [`alligator`](https://aagillet.github.io/MorphoRegions/reference/alligator.md)
  : Measurements from the vertebral column of an alligator
- [`dolphin`](https://aagillet.github.io/MorphoRegions/reference/dolphin.md)
  : Measurements from the vertebral column of a dolphin
- [`musm`](https://aagillet.github.io/MorphoRegions/reference/musm.md) :
  Measurements from the vertebral column of a mouse
- [`porpoise`](https://aagillet.github.io/MorphoRegions/reference/porpoise.md)
  : Measurements from the vertebral column of three porpoises
