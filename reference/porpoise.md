# Measurements from the vertebral column of three porpoises

Linear and angular measurements from Phocoena phocoena NRM 815072
(`porpoise1`), NRM 835011 (`porpoise2`), and NRM 855083 (`porpoise3`).

## Usage

``` r
data("porpoise")
```

## Format

Each is a data frame with 58, 56, and 59 vertebrae (respectively) and 16
measurements. Column 1, Vertebra, contains the positional information.

## References

Gillet, A., Frederich, B., Pierce, S. E., & Parmentier, E. (2022).
